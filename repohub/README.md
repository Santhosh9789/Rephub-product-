# RepoHub – Secure DevOps Repository & Monitoring Platform

RepoHub is a self-hosted DevOps repository management tool built for internal teams and enterprises seeking full control over their code, CI/CD pipelines, and project monitoring — all in one platform.

This repository contains the source code for RepoHub.

## Structure

*   `/frontend`: Contains the React.js and TailwindCSS frontend application.
*   `/backend`: Contains the Node.js and Express.js backend application.
